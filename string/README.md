## 字符串设计与下标约定

`AString` 保留课件的核心设计：

- `char* ch`：动态字符数组；
- `curLength`：实际长度；
- `maxSize`：当前容量；
- 子串提取、比较、赋值、连接、下标访问；
- BF 朴素模式匹配；
- KMP 模式匹配；
- `pi` 前缀函数计算。

`getPi(int pi[])` 使用从 0 开始的下标：`pi[i]` 是模式串 `ch[0..i]` 的最长相等真前后缀长度，`pi[0] = 0`。失配时用 `pi[j - 1]` 回退已匹配长度 `j`，不使用 `-1` 哨兵。`Find_KMP()` 仍从目标串的第 `k` 个字符开始查找，返回首次匹配的起始下标；空模式串、非法 `k` 或未找到时返回 `-1`。

## 必要修正

1. 课件的子串运算声明返回 `AString&`，但实现返回局部对象；这里改为按值返回，避免悬空引用。
2. 课件类声明写 `Find_KMP`，后续算法实现写 `fastFind`；仓库统一保留 `Find_KMP()` 作为公开接口，`fastFind()` 作为内部辅助函数。
3. 依照本次提供的 `pi` 写法，将课件的 `getNext()` 和 KMP 失配回退改为 `getPi()` 及 `pi[j - 1]`。对课件的 `next[0] = -1` 定义，有 `next[j] = pi[j - 1]`（`j >= 1`）；这是表示方式与下标约定的调整，匹配算法仍为 KMP。
4. 赋值运算补充同步 `maxSize`，并处理自赋值。
