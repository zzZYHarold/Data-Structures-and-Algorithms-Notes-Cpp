## 课程内容

课件使用链式结构表示广义表，并为每一个表（包括子表和空表）设置附加头结点。

`GenList.h` 保留课件中的核心结点设计：

- `utype = 0`：附加头结点，`info.ref` 保存引用计数；
- `utype = 1`：原子结点，`info.value` 保存原子值；
- `utype = 2`：子表结点，`info.hlink` 指向子表的附加头结点；
- `tlink`：指向同层下一个表结点。

同时保留课件中的 `Items<T>` 和 `GenList<T>` 设计。

## 已整理的主要操作

### 表头与表尾

- `Head(Items<T>& x)`：返回第一个表元素；
- `Tail(GenList<T>& lt)`：返回除表头外其余元素组成的表；
- `First()` / `Next()`：访问同层表结点。

### 广义表复制

课件给出的 `Copy(GenListNode<T>* ls)` 使用递归方式同时处理：

- 当前结点；
- 子表 `hlink`；
- 同层后继 `tlink`。

该算法只适用于 **无共享、非递归广义表**。如果存在共享子表，会造成共享部分被重复复制；如果存在递归表，则递归无法终止。

### 长度与深度

- `Length()`：统计最外层表元素个数；
- `Depth()`：递归计算非递归广义表的深度。

按照课件定义：

- 空表深度为 `1`；
- 只含原子的线性表深度为 `1`；
- 子表深度取所有子表最大深度后再加 `1`。

### 删除指定原子

课件给出了递归函数 `delvalue`，用于删除广义表中所有值等于指定值的原子结点。

仓库增加了一个公开包装接口：

```cpp
void DeleteValue(const T& x);
```

内部仍直接采用课件的递归删除思想：

1. 连续删除同层开头满足条件的原子结点；
2. 遇到子表则递归进入子表删除；
3. 再递归处理同层后续结点。

### 广义表释放与引用计数

完整课件正式给出了 `Remove()` 算法。

删除一个表时，先令其附加头结点的引用计数 `ref--`；只有当 `ref <= 0` 时，才真正释放该表。扫描当前层时，如果遇到子表结点，则递归调用 `Remove()` 处理其子表。

析构函数：

```cpp
~GenList() {
    Remove(first);
}
```

因此当前实现已经按照课件的引用计数思路处理整表释放。

## 相较课件的必要修正 / 补充

1. 课件构造函数中局部变量 `first` 会遮蔽数据成员，本实现修正为直接初始化成员 `first`。
2. 课件后续删除算法默认附加头结点的引用计数初值为 `1`，本实现显式设置 `first->info.ref = 1`。
3. 课件给出了私有递归函数 `delvalue`，但没有在类声明中提供直接调用接口；仓库补充 `DeleteValue()` 作为公开包装函数。
4. 为保证动态链式结构可正常复制，补充复制构造函数与赋值运算符；底层递归复制仍使用课件的 `Copy()` 思路。
5. `AppendAtom()` / `AppendSublist()` 是为了在课件未给出完整建表算法时方便构造和测试而增加的辅助接口，不属于课件原接口。

## 使用范围

课件中的复制、深度以及递归删除算法主要针对非递归广义表。递归表的深度为无穷大，直接使用这些递归算法也可能无法终止；共享表则还需要特别注意引用计数与共享关系。
