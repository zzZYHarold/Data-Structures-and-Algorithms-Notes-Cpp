## 排序算法特性表

`n` 是参加排序的记录数。辅助空间计入递归栈，比较排序码和搬移一条记录按常数开销计。平均列采用教材常见的随机排列分析。

| 排序算法 | 最好时间 | 平均时间 | 最坏时间 | 辅助空间 | 稳定性 |
| --- | --- | --- | --- | --- | --- |
| 直接插入排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 折半插入排序 | O(n log n) | O(n²) | O(n²) | O(1) | 稳定 |
| 希尔排序 | O(n log n) | 依赖增量序列 | O(n²) | O(1) | 不稳定 |
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | 平均 O(log n)，最坏 O(n) | 不稳定 |
| 直接选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 锦标赛排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 堆排序 | O(n)（全部等键时可达） | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 迭代二路归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 递归静态链表归并 | O(n log n) | O(n log n) | O(n log n) | O(log n) | 稳定 |

- 折半插入每趟做折半查找，插入位置之后的元素仍须后移。希尔排序的最好、最坏列按第 33 页代码的 `gap = n/2, gap/2, …, 1` 向下取整增量计算。
- 快排的平均时间和栈深按互异关键码的随机排列计算。随机选基准也可能遇到极不均衡的划分，全部等键时本章的两种划分都会退化。
- 堆排序的建堆阶段为 O(n)。课件给出的 O(n log n) 是堆排序的通用时间上界。本实现遇到双亲与最大子女等键时停止下筛，因此全部等键时每次取堆顶只花 O(1)。
- 稳定性看相同关键码的原始相对次序。折半插入放在已有等键元素之后，锦标赛和两种归并在键相同时优先选择左侧。静态链表建表占 O(n)，表中的 O(log n) 指已有静态链表上的排序开销。

### 首元素作基准时的快排搬移次数

- **前后指针法（第 61 页）。** 已升序时，每次划分只有常数次基准相关的赋值，全程搬移 O(n)。若多层递归都遇到近乎单边的划分，且每层仍做线性次数的交换，全程搬移可达 O(n²)。课件用 `[4, 5, 3, 1, 2]` 示范，第一趟得到 `[2, 3, 1, 4, 5]`，再划分左侧得到 `[1, 2, 3, 4, 5]`。
- **挖坑法（第 62 页）。** 已升序时全程搬移 O(n)。每次划分交替从两侧填坑，两侧搬入的次数最多差 1。一趟的搬移次数至多是较短侧长度的两倍再加常数。把这部分开销计给较短侧的记录，每次计入时该记录所在区间至少减半，因此全程搬移上界为 O(n log n)。课件用 `[6, 7, 1, 2, 3, 4, 5, 0]` 示范一趟划分，基准 6 就位后得到 `[0, 5, 1, 2, 3, 4, 6, 7]`。
- 搬移与比较分别计数。即使已升序、每层只写回基准，找划分位置仍会扫描当前子区间，所以两种写法的最坏总时间都是 O(n²)。

## 接口与下标

- 类型和函数位于 `sorting`。顺序表使用 `dataList<T, Field>`，`T` 是排序码类型，`Field` 对应课件的 `otherdata`，省略时为空类型。两者须可默认构造、复制，排序码的 `<` 定义严格弱序。显式使用记录的 `==` 时还需排序码支持 `==`。
- `dataList(capacity)` 创建长度为 0 的定容表。用 `Append({key, otherdata})` 装入记录，满表返回 `false`。`Length()` 返回有效记录数，`operator[]` 使用 0-based 下标。
- 插入、交换及直接选择排序使用 **0-based 闭区间** `[left, right]`。全表传 `0, Length()-1`，空区间可传 `[left, left-1]`。两个 `Partition` 需要非空区间并返回基准就位的下标。锦标赛、堆排序和迭代归并直接接收整张表。
- `ShellPass(table, left, right, gap)` 在同样的闭区间内按指定增量做一趟组内插入。`gap` 必须为正，大于或等于区间长度时直接结束。完整的 `Shellsort` 从区间长度的一半开始逐次折半。
- `merge(source, destination, left, middle, right)` 合并相邻的两个有序段，写入另一张表相同下标的位置。`MergePass(source, destination, len)` 对前一趟得到的长度为 `len` 的有序段做一趟归并，末段可短于 `len`。传入两张不同的表，目标表需要先用 `Append` 建立有效长度，调用 `MergePass` 时两表长度相同。
- `staticlinkList<Type, Field>` 从顺序表装入连续的 **1-based** 记录，初始时各自独立。`MergeSort(left, right)` 按存储下标拆分并重建指定范围的链，返回新链首，零参数重载处理全表。0 是空链标记，`Link(0)` 也可读取最新归并的链首。用 `Link(index)` 沿链访问，`operator[]` 始终读取原存储位置。`ListMerge` 的两个输入链需互不相交，并各自有序。

```cpp
#include "sorting/include/Sort.h"
#include "sorting/include/staticlinkList.h"

sorting::dataList<int, char> records(3);
records.Append({25, 'A'});
records.Append({8, 'B'});
records.Append({25, 'C'});

sorting::staticlinkList linked(records);
for (int node = linked.MergeSort(); node != 0; node = linked.Link(node)) {
    const auto& record = linked[node]; // 依次读取 8B、25A、25C
}

sorting::BinaryInsertSort(records, 0, records.Length() - 1); // 相同顺序
```

## 第 119 页作业

1. **A，快速排序。** 按本章的从右向左冒泡和直接选择，两趟后前两项已就位。插入排序两趟后前三项有序。题给的前两项 `2, 1` 排除了这三种。用首元素作基准的快排可从 `[20, 1, 2, 9, 8, 10, 6, 4]` 出发，先得到 `[4, 1, 2, 9, 8, 10, 6, 20]`，再划分左侧即得到题给序列。
2. **B，折半插入排序。** 查找位置时遇到相等关键码继续向右，保持相等记录的原序。
3. **B，希尔排序。** 增量大于 1 时，一趟只保证各个间隔组内有序。例如 `[3, 1, 4, 2]` 经过 `gap=2` 的一趟仍是原序列，四个位置都与最终升序不同。

第 4 题的输入为 `[34, 85, 43, 72, 95, 40, 49, 58, 65, 20]`。

| 步骤 | 结果 |
| --- | --- |
| 自底向上建立最大堆 | `[95, 85, 49, 72, 34, 40, 43, 58, 65, 20]` |
| 排出 95 后重新下筛 | `[85, 72, 49, 65, 34, 40, 43, 58, 20, 95]`，前 9 项是调整后的最大堆，末项 95 已就位 |
| 二路归并第一趟 | `[34, 85, 43, 72, 40, 95, 49, 58, 20, 65]`，每段至多 2 项 |
| 二路归并第二趟 | `[34, 43, 72, 85, 40, 49, 58, 95, 20, 65]`，末尾两项已作为单独一段复制 |
| 希尔排序 `gap=3` 一趟 | `[20, 58, 40, 34, 85, 43, 49, 95, 65, 72]` |
